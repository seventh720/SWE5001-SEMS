## 保留的边界与后续优化

- 当前 Lightsail 是单主机、共享 PostgreSQL 实例的三服务部署。增加容器不等于主机级 HA，也没有云上自动扩容或扩容收益证明。
- 本地 Catalog 在 25/50/100 VU 下，1→2 副本成功吞吐中位数比为 1.14× / 1.79× / 3.09×；Admission 为 0.96× / 1.35× / 1.46×。两次故障实验完成数据核对，但存在 503/502 中断，不能称为零中断。详情和原镜像口径见实验报告。
- 安全扫描门禁、GHCR digest 镜像交付已通过当前 main 流水线；Spring 的有期限适用性例外仍见[安全文档](security.md)，不等于所有依赖漏洞已消除。
- 仍待补充：云端容量/恢复与兼容回滚证据、常驻监控和告警、OpenAPI 自动符合性校验、关键集成覆盖采集。邀请历史分页和更多真实浏览器错误分支按实际需求安排。
- 无需为当前展示增加支付、主题、多语言或继续拆分服务。密钥仍为受限主机文件；运行环境和 proposal 的差异需如实说明。
