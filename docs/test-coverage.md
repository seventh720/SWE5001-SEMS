前端语句覆盖率 81.92%，函数覆盖率 71.97%。TypeScript 与 Vite 生产构建通过。前端由 Vitest V8 采集；后端由 Maven/JaCoCo 采集。后端本轮新增 8 项回归并重新通过 `mvn verify`；后端加权行/分支覆盖率从 16.4%/13.8% 提升至 18.3%/15.9%。

真实 HTTP/PostgreSQL 验收独立执行，包含数据库事务、权限、并发和跨服务恢复，不计入以上覆盖率。不能把验收通过写成“后端整体覆盖充分”或把这些百分比换算为需求完成率。当前 CI 未设置覆盖率百分比阈值；失败测试、类型检查和构建会阻断对应作业。

## 历史相机与页面回归（2026-10-19）

相机切换修改前一轮起点为前端 100 项、行覆盖率 83.19%、分支覆盖率 74.03%；新增 11 项有业务意义的回归：

| 场景 | 检查结果 |
|---|---|
| 报名名单翻页失败、重试 | 失败后旧联系人不残留，重试仍请求当前页 |
| 预约当前信息及关闭状态 | 展示最新标题/地点；关闭后不出现报名入口；无法取当前信息有提示 |
| 删除预约失败 | 不错误删除界面记录，允许再次操作 |
| 删除末页唯一预约 | 测试先失败；修复后自动回到有效页，删除/加载期间禁用翻页 |
| 相机等待播放手势时关闭 | 释放视频轨道，不发起核销 |
| 读取视频帧失败 | 停止摄像头并给出可重试提示 |
| 浮层定位 | 靠右不溢出、下方不足时向上展开、视口缩短后限高、关闭清理监听、无 Popover API 时保留 CSS 回退 |
| 登录保护 | 未登录不显示受保护内容，保留 path/query/hash；已登录允许进入 |

上一轮新增的组织事件检索、分页回退、视频方向变化测试继续通过。`scripts/event-directory-acceptance.py` 在真实本地 PostgreSQL/API 验证了跨页检索、大小写、字面 `%`/`_`、组织隔离、多人共享编辑/发布、旧版本冲突及实时降级；已加入工作树中的 CI 配置，已在 PR #14 远端集成检查通过。

相机切换新增 2 项测试，检查指定方向不存在时不静默使用另一方向，以及快速切回后置时释放迟到的前置流。原设备切换测试已改为前置/后置切换及停止顺序测试。该次 113 项全部通过；当前计数见本文开头。

## 历史后端回归（2026-10-19）

新增 7 项取消状态机测试：未授权不能取得写锁、空原因不改变发布状态、旧版本拒绝取消、草稿/发布中/更新中拒绝取消、暂停活动进入持久化取消流程、相同请求复用 operation 而不同原因冲突、过期回执不能结束另一操作。另补 1 项活动分页参数测试，覆盖负页码、零页大小、超大页大小和 offset 溢出。

这些单测检查状态判断和写入调用边界，不证明数据库锁或事务回滚正确性；实际事务、并发、跨服务恢复继续依赖独立 PostgreSQL/API 验收。

## 覆盖边界与后续优先级

- **手机实机已确认**：用户确认手机摄像头扫码正常，浏览器效果正常。单元/API 回归仍不能证明某型号设备的识别率或全部系统权限场景；本项目没有声称做过识别率测量。
- **仍待工程补充**：把关键数据库/API 验收覆盖率另行采集，明确 Controller、SQL/JPA、事务和重试路径的实测覆盖；目前 JaCoCo 数字只反映单元测试。无需为了提高数字而用大量 mock 代替数据库测试。
- **本版云端复测**：250 VU读取通过、混合未通过；500 VU未执行；1000 VU未执行。详见[报告](evidence/2026-10-22-cloud-capacity/README.md)。旧性能、扩容/故障与调参记录已按用户要求清理。
- **仍待课程实验**：读延迟/内部超时改进后的复测、100 VU 十分钟稳态、独立扩容收益、云端故障恢复时间、兼容回滚；现有本地并发和恢复验收不是这些实验结果。
- **仍待交付检查**：自动 OpenAPI 契约符合性仍未实现；lint、静态/依赖/secret/镜像扫描已在上方 PR #23 主分支流水线通过。
- **可后续补测**：复杂编辑器错误分支、邀请生命周期前端、更多真实浏览器键盘/缩放/滚动场景。单元测试中的定位几何是模拟值；保留此前浏览器实测作为独立证据。

## 重现

```bash
npm --prefix apps/web run test:coverage
npm --prefix apps/web run build
mvn verify
python3 scripts/ci/coverage.py frontend
python3 scripts/ci/coverage.py backend
```

数据库/API 验收必须使用独立本地或 CI 测试栈及其环境变量，见 [CI 操作说明](ci.md)。不要把会创建测试数据、停启服务的验收脚本直接指向云端展示环境。
