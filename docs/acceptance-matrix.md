# 能力与质量验收矩阵

整理日期：2026-10-23。最近发布为 `fb27bbf`（[CI 与部署](https://github.com/seventh720/SWE5001-SEMS/actions/runs/39751659240)），容量测量单独对应 `f69d49d`。下表区分已完成检查与仍待验证的工程目标；测试通过不表示所有环境和负载均已覆盖。

| 能力或目标 | 已有证据 | 待验证或限制 |
|---|---|---|
| 组织管理 | 组织管理员总览、活动/成员组合筛选、服务端分页、已结束活动保护，[验收记录](evidence/2026-10-20-organization-management/verification.md) | 更多真实浏览器错误分支按需求补充 |
| API 与数据边界 | 三份 OpenAPI、独立镜像/schema/账号/迁移、跨 schema 访问拒绝检查 | 自动请求/响应契约符合性尚未接入 CI |
| 业务闭环 | 注册、组织授权、发布、预订、出票、核销、统计、取消 | API 验收与设备实测分别记录 |
| 平台复用 | 不同组织的讲座与工作坊共用 API 和部署，组织内协作、跨组织隔离 | 未测量相对独立开发的工时节省 |
| 库存与幂等 | 两个 Admission 实例，100 请求竞争 10 名额，数据库确认不超卖；同键重放、异载荷拒绝、取消竞争和重复核销 | 只覆盖记录中的并发场景，不代表吞吐收益 |
| 会话与权限 | 1 小时 JWT/重登、匿名/跨组织/他人订单/未分配工作人员拒绝、最后管理员保护、认证限流 | 网关限流不是分布式限流 |
| 容量 | 50 活动/1000 账号，250 VU 读取通过；混合客户端通过但 4 次内部 504 导致服务端门禁失败，[完整记录](evidence/2026-10-22-cloud-capacity/README.md) | 500/1000 VU 未执行；100 VU 十分钟稳态、p95 < 3 秒和意外错误率 < 1% 仍待按指定方案验证 |
| 独立扩容 | 本地 Admission 2→3→2 动态路由与正确性检查 | Catalog 和 Admission 各自 1/2 副本的受控云端收益对照待完成 |
| 故障恢复 | 本地/CI 冷重启、同键重放和回执恢复检查 | 云端 60 秒恢复目标、故障期间库存与提交记录核对待完成 |
| 安全交付 | HTTPS、内部令牌、权限拒绝、源码/依赖/secrets/镜像扫描与 main-only digest 发布 | 有限时效适用性例外见[安全说明](security.md)；扫描不替代渗透或全部业务权限检查 |
| 备份与回滚 | 部署前数据库备份、不可变镜像锁、就绪检查与发布指针 | 兼容旧镜像回滚、数据库恢复演练及定期异地备份待完成 |

测试与历史覆盖率见[测试说明](test-coverage.md)，实验方法见[性能与可用性](performance-and-availability.md)，后续任务见[技术改进计划](roadmap.md)。验证记录应保留 commit、镜像 digest、配置、时间、数据、原始结果及数据库核对；失败结果也保留。
